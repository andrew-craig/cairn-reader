## Description

Explore Fetcher currently has no panic recovery — an unhandled panic will crash the service. After the shared middleware package is extracted (task_6995) and Explore Fetcher is migrated to chi (task_2865), add recovery middleware to all services that lack it.

## Services Missing Recovery

- Explore Fetcher — no recovery at all
- Explore Recommender — needs verification

## Requirements

- Add `pkg/middleware.SafeRecovery()` to Explore Fetcher's middleware chain
- Verify and add recovery to Explore Recommender if missing
- Ensure recovery returns proper JSON error responses (500)
- Ensure recovery logs the panic with stack trace

## Acceptance Criteria

- [ ] All services have panic recovery middleware
- [ ] Panics produce 500 JSON responses, not connection drops
- [ ] Panics are logged with stack traces
