Implement services/read/email/internal/processor/content_extractor.go

## Requirements
Sanitize email HTML and generate content hash. NO readability extraction — sanitize only for now.

### Pipeline:
1. Receive pre-cleaned HTML from EmailCleaner
2. Sanitize with bluemonday (same policy as content service sanitizer)
3. Generate SHA-256 content hash of sanitized HTML for deduplication
4. Extract plain text version for content_text field

### Bluemonday policy (match content service):
- Allow: p, h1-h6, strong, em, code, blockquote, pre
- Allow: ul, ol, li, dl, dt, dd
- Allow: table, thead, tbody, tr, th, td (with colspan/rowspan)
- Allow: a (href, title) with rel=nofollow noreferrer
- Allow: img (src, alt, width, height), figure, picture, source
- Allow: br, hr

## Interface
- Extract(cleanedHTML string) -> (ProcessedEmailContent, error)

## ProcessedEmailContent struct:
- SanitizedHTML string
- PlainText string
- ContentHash string (SHA-256 hex)

## Reference
- Content service sanitizer: services/read/content/internal/processor/sanitizer.go
