Reported: the You page (mobile) and Sidebar You-section (web) show incorrect
counts for Bookmarks and Votes.

## Root causes

**Bookmarks — structurally always 0, and wrong filter besides.**
`YouScreen.tsx`/`Sidebar.tsx` read `total_count` from
`ReadService.listUserContents({ limit: 1 })` (no `is_favorite` filter). Two bugs:
1. The content service's cursor-paginated `GET /api/v1/content/user/{user_id}`
   endpoint never populates `pagination.total` (deliberate — a test asserts it's
   absent, avoiding a `COUNT(*)` on every scroll-pagination request), so
   `total_count` was always 0 on the client.
2. Even if populated, the call omitted `is_favorite: true`, so it would have
   counted all saved articles, not just bookmarks.

**Votes — count included votes on soft-deleted articles.**
`GetUserVoteStats` (backend, explore/recommender) counted every vote row for
the user with no filter on the article's `deleted` flag, while the Votes list
(`GetUserVotedArticles`) filters `deleted = false`. Once a voted-on article
passes the 90-day retention soft-delete, the You-page count kept including it
while the list dropped it, so the two diverged.

## Fix

- Added `GET /api/v1/content/user/{user_id}/count` (content service): a
  dedicated `COUNT(*)` endpoint (mirrors the existing vote-stats pattern),
  backed by a new `CountByUser` repository method. Kept off the hot
  cursor-pagination path.
- Mobile and web `ReadService.countUserContents()` call it with
  `is_favorite: true` instead of relying on `listUserContents`' never-populated
  total.
- `GetUserVoteStats` (explore/recommender) now joins `articles` and filters
  `deleted = false`, matching `GetUserVotedArticles`' semantics.
- Incidental fix: `TestGetUserVoteStats_Aggregate`'s pre-existing integration
  test used a non-UUID user ID, failing `EnsureUserExists`'s UUID validation
  against a real DB — it only ever skipped silently for lack of a reachable
  test DB, so this was never actually verified before. Fixed to use a real
  UUID.

## Verification

- Go: `go build`/`go vet`/`go test ./...` clean for both `services/read/content`
  and `services/explore`.
- New votes-stats test (`TestGetUserVoteStats_ExcludesDeletedArticles`) run
  against a disposable local Postgres container to confirm the join/filter
  behaves correctly (container removed after).
- TypeScript: `tsc --noEmit` clean for both `apps/mobile` and `apps/web`.
