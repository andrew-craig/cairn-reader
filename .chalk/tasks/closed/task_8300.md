Implement services/read/email/internal/processor/email_cleaner.go

## Requirements
Email-specific pre-cleaning before sanitization. Strip email artifacts that aren't part of the newsletter content.

### Must strip:
- Tracking pixels: 1x1 images, known tracker domain images (e.g. open.substack.com, list-manage.com pixel endpoints)
- Unsubscribe links/footers: common patterns like 'Unsubscribe', 'Manage preferences', 'Update your preferences'
- Email client artifacts: 'View in browser', 'View this email in your browser', 'Click here to view'
- Preheader text (hidden preview text common in email HTML)

### Should preserve:
- All meaningful content images (non-tracking)
- Newsletter body content
- Links within the content (non-unsubscribe)

## Interface
- Clean(htmlBody string) -> (cleanedHTML string, error)

## Implementation approach
- Use golang.org/x/net/html to parse and walk the DOM
- Remove nodes matching tracking/artifact patterns
- Return serialized cleaned HTML

## Tests
- Test tracking pixel removal (1x1 img, known domains)
- Test unsubscribe footer removal  
- Test 'view in browser' removal
- Test that content images and links are preserved
