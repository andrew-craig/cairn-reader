Add GitHub Actions build workflows and production docker-compose entries for the email ingest service. The dev docker-compose already has both services; prod and CI are missing.

## 1. GitHub Actions workflows (2 new files)

Following the pattern of the existing ingest-rss workflows:
- `docker-build-ingest-rss.yml` → model for `docker-build-ingest-email.yml`
- `docker-build-ingest-rss-worker.yml` → model for `docker-build-ingest-email-worker.yml`

Each workflow should:
- Trigger on push/PR to `main` with paths scoped to `services/read/email/**`, `services/read/internal/**`, `services/read/go.mod`, `services/read/go.sum`, and its own workflow file
- Support `v*` tags and `workflow_dispatch`
- Build & push to `ghcr.io` with image names `cairn-ingest-email` and `cairn-ingest-email-worker`
- Reference `services/read/email/Dockerfile` and `services/read/email/Dockerfile.worker` respectively
- Use `linux/arm64` platform and GHA build cache (matching existing conventions)

Add `email-ingest` and `email-ingest-worker` services to `infrastructure/docker/prod/docker-compose.yml`, mirroring the entries already present in `infrastructure/docker/dev/docker-compose.yml` but using the GHCR image references instead of local builds.
