## Description

The User Service has a comprehensive set of middleware in `services/users/internal/middleware/` that should be available to all services. Extract the reusable, production-ready variants into a new shared `pkg/middleware` package.

## Current State

User Service middleware (`services/users/internal/middleware/`):
- `recovery.go` — 6 variants (Recovery, RecoveryWithDetails, SafeRecovery, etc.)
- `cors.go` — Full CORS implementation (basic, strict, development, production)
- `security.go` — HTTPS enforcement, security headers, cache control
- `rate_limit.go` — Token bucket rate limiter (per-IP, per-user)
- `authorization.go` — User ownership checks (may stay service-local)

## Requirements

- Create `pkg/middleware/` package with production-ready middleware:
  - `recovery.go` — Extract `SafeRecovery()` (the production-safe variant)
  - `cors.go` — Extract CORS middleware with configurable origins
  - `security.go` — Extract `SecureHeadersRelaxed()` and `RequireHTTPS()`
  - `rate_limit.go` — Extract rate limiting with configurable limits
- Update User Service to import from `pkg/middleware` instead of local package
- Keep `authorization.go` in User Service (it's service-specific)
- Add tests for the shared package

## Acceptance Criteria

- [ ] `pkg/middleware` package exists with recovery, CORS, security, and rate limiting
- [ ] User Service imports from shared package
- [ ] All User Service tests pass
- [ ] Shared package has its own tests
