## Goal
An empty SwiftUI app in `apps/ios` that builds and runs its tests on a macOS runner on every PR. Everything after this is verified through that job: agent sessions run on Linux and cannot build Swift for iOS, so CI is the verification loop.

## Plan
- [ ] `apps/ios/CairnReader.xcodeproj`: one app target `CairnReader`, one unit-test target `CairnReaderTests` (Swift Testing). Bundle id `com.cairnapp.cairnreader`, iOS 26 deployment target, iPhone and iPad, portrait only on iPhone (matches `app.json`), Swift 6 language mode.
- [ ] Use file-system-synchronized groups (`PBXFileSystemSynchronizedRootGroup`) for `CairnReader/` and `CairnReaderTests/` so later tasks add Swift files without touching `project.pbxproj`. The project file is hand-written here; if it will not open cleanly the 5-minute alternative is the owner creating it in Xcode with the same settings.
- [ ] Source layout: `App/`, `Models/`, `Services/`, `Store/`, `Features/<Screen>/`, `Resources/`.
- [ ] Carry over from `apps/mobile/ios/CairnReader`: `CairnIcon.icon`, `PrivacyInfo.xcprivacy` (re-derive the required-reason entries for native code), `ITSAppUsesNonExemptEncryption = false`, the `com.cairnapp.cairnreader` URL scheme, ATS left at default (no arbitrary loads). Launch screen: background colour only.
- [ ] `App/CairnReaderApp.swift` with a placeholder root view.
- [ ] `.github/workflows/ios-checks.yml` on `macos-26`, paths `apps/ios/**`: `xcodebuild build` and `xcodebuild test` against an iOS 26 simulator, warnings as errors.
- [ ] `apps/ios/CLAUDE.md` stub: layout, how to build and test, "verify through CI".
- [ ] Root `.gitignore` entries for `xcuserdata`, `DerivedData`.

## Verify
- `ios-checks` is green on the PR with one trivial passing test.
- Owner opens the project in Xcode and runs it on a simulator.
